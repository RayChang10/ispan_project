# FastMCP-FastAgent 職缺搜尋系統 - 快速開始指南

## 🚀 快速啟動

### 1. 環境準備

```bash
# 1. 設定環境變數
export OPENAI_API_KEY="your_openai_api_key_here"
export MILVUS_HOST="localhost"
export MILVUS_PORT="19530"

# 2. 安裝依賴
pip install -r requirements.txt
```

### 2. 啟動 Milvus 向量資料庫

```bash
# 進入 commitLLM 目錄並啟動 Milvus
cd commitLLM
docker-compose up -d

# 檢查服務狀態
docker-compose ps
```

### 3. 設定職缺資料庫

```bash
# 回到專案根目錄
cd ..

# 執行資料庫設定腳本
python3 scripts/setup_job_search_data.py
```

### 4. 測試系統功能

```bash
# 執行整合測試
python3 scripts/test_job_search_integration.py

# 執行工作流程示範
python3 scripts/demo_job_search_workflow.py
```

### 5. 啟動後端服務

```bash
# 啟動 FastAPI 後端
python3 -m uvicorn backend.fastapi_app:app --host 0.0.0.0 --port 8001 --reload
```

## 📱 使用方式

### 方式一：API 調用

```python

# 1. 職缺搜尋

    "query": "Python 開發工程師",
    "top_k": 10
})
jobs = response.json()

# 2. 根據履歷搜尋
response = requests.post("http://localhost:8001/api/job_search/search_by_resume", json={
    "resume_data": {
        "name": "張三",
        "skillList": ["Python", "Django", "PostgreSQL"],
        "desired_position": "後端工程師"
    },
    "query": "後端開發"

# 3. 履歷健檢
response = requests.post("http://localhost:8001/api/job_search/resume_health_check", json={
    "resume_data": {
        "name": "張三",
        "skillList": ["Python", "Django"],
        "workList": [{"company": "ABC", "title": "工程師"}]
    }
})
health_check = response.json()
```

## 📊 API 端點清單

### 職缺搜尋相關
- `POST /api/job_search/search` - 職缺搜尋
- `POST /api/job_search/search_by_resume` - 履歷職缺搜尋
- `POST /api/job_search/analyze_fit` - 契合度分析
- `POST /api/job_search/resume_health_check` - 履歷健檢
- `GET /api/job_search/status` - 服務狀態

### 工作流程管理
- `POST /api/workflow/set_resume` - 設定履歷
- `POST /api/workflow/search_jobs` - 工作流程職缺搜尋
- `POST /api/workflow/select_job` - 選擇職缺
- `POST /api/workflow/analyze_fit` - 工作流程契合度分析
- `POST /api/workflow/resume_health_check` - 工作流程履歷健檢
- `POST /api/workflow/start_mock_interview` - 開始模擬面試
- `GET /api/workflow/status` - 工作流程狀態
- `POST /api/workflow/reset` - 重置工作流程

### 現有功能（保持不變）
- `POST /api/interview` - 面試對話
- `POST /api/get_question` - 獲取面試問題
- `POST /api/analyze_answer` - 分析回答
- 其他現有 API...

## 🎯 完整工作流程範例

```python
import requests

base_url = "http://localhost:8001"

# 1. 設定履歷
resume_data = {
    "name": "陳小明",
    "age": "28",
    "location": "台北市",
    "summary": "具備3年Python開發經驗的後端工程師，熟悉Django、FastAPI框架，有豐富的資料庫設計與API開發經驗。",
    "keywords": "Python, Django, FastAPI, PostgreSQL, Redis, Docker",
    "skillList": ["Python", "Django", "FastAPI", "PostgreSQL", "Redis", "Docker", "Git"],
    "workList": [
        {
            "company": "科技公司A",
            "title": "後端工程師",
            "start": "2021-03",
            "end": "Present",
            "bullets": [
                "開發RESTful API，服務日活躍用戶10萬+",
                "設計並優化資料庫架構，查詢效能提升50%",
                "導入Docker容器化部署，提升開發效率30%"
            ]
        }
    ],
    "eduList": [
        {
            "school": "台灣大學",
            "degree": "學士",
            "major": "資訊工程",
            "start": "2017-09",
            "end": "2021-06"
        }
    ]
}

print("🚀 開始完整工作流程示範...")

# 步驟1: 設定履歷
print("\n📝 步驟1: 設定履歷")
response = requests.post(f"{base_url}/api/workflow/set_resume", json={
    "resume_data": resume_data
})
result = response.json()
print(f"結果: {result['status']}")
print(f"可用階段: {result.get('next_stages', [])}")

# 步驟2: 搜尋職缺
print("\n🔍 步驟2: 搜尋職缺")
response = requests.post(f"{base_url}/api/workflow/search_jobs", json={
    "query": "Python 後端工程師"
})
result = response.json()
print(f"結果: {result['status']}")
if result.get('jobs'):
    print(f"找到 {len(result['jobs'])} 個職缺")
    for i, job in enumerate(result['jobs'][:3], 1):
        print(f"  {i}. {job['job_title']} - {job['company_name']}")

# 步驟3: 選擇職缺
print("\n🎯 步驟3: 選擇職缺")
response = requests.post(f"{base_url}/api/workflow/select_job", json={
    "job_index": 0
})
result = response.json()
print(f"結果: {result['status']}")
if result.get('selected_job'):
    job = result['selected_job']
    print(f"已選擇: {job['job_title']} - {job['company_name']}")

# 步驟4: 分析契合度
print("\n📊 步驟4: 分析契合度")
response = requests.post(f"{base_url}/api/workflow/analyze_fit")
result = response.json()
print(f"結果: {result['status']}")
if result.get('analysis'):
    analysis = result['analysis'][:200] + "..." if len(result['analysis']) > 200 else result['analysis']
    print(f"分析摘要: {analysis}")

# 步驟5: 履歷健檢
print("\n🏥 步驟5: 履歷健檢")
response = requests.post(f"{base_url}/api/workflow/resume_health_check")
result = response.json()
print(f"結果: {result['status']}")
if result.get('health_check'):
    health_check = result['health_check'][:200] + "..." if len(result['health_check']) > 200 else result['health_check']
    print(f"健檢摘要: {health_check}")

# 步驟6: 查看最終狀態
print("\n📈 步驟6: 查看工作流程狀態")
response = requests.get(f"{base_url}/api/workflow/status")
result = response.json()
if result.get('workflow_status'):
    status = result['workflow_status']
    print(f"當前階段: {status['current_stage']}")
    print(f"履歷狀態: {'✅' if status['has_resume'] else '❌'}")
    print(f"搜尋結果: {'✅' if status['has_search_results'] else '❌'}")
    print(f"選中職缺: {'✅' if status['has_selected_job'] else '❌'}")

print("\n🎉 工作流程示範完成！")
```

## 💡 小貼士

1. **效能優化**: 首次執行會比較慢，因為需要向量化和建立索引
2. **資料更新**: 如果要更新職缺資料，重新執行 `setup_job_search_data.py`
3. **錯誤排查**: 查看終端輸出的詳細錯誤訊息
4. **API 文件**: 訪問 `http://localhost:8001/docs` 查看完整 API 文件
5. **狀態管理**: 使用工作流程 API 時，系統會自動管理狀態轉換
