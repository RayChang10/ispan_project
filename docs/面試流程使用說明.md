# JobMate360 面試流程使用說明

## 🎯 系統概述

JobMate360 虛擬面試系統完全按照 `流程.txt` 的要求設計，提供完整的自我介紹與面試體驗。

## 📋 面試流程架構

### 階段 1: 自我介紹階段
- **觸發**: 按下「開始面試」按鈕
- **狀態**: 自我介紹 Agent 啟動，其他 Agent 不啟動
- **功能**: 收集用戶自我介紹內容
- **特點**: 不管使用者說什麼都認為是在自我介紹

### 階段 2: 自我介紹分析階段
- **觸發**: 輸入「完成自我介紹」或「開始面試」
- **功能**: 按照 6 個標準分析自我介紹
- **標準**:
  1. 開場簡介（身份與專業定位）
  2. 學經歷概述
  3. 核心技能與強項
  4. 代表成果
  5. 與職缺的連結
  6. 結語與期待

### 階段 3: 面試模式階段
- **觸發**: 自我介紹分析完成後自動進入
- **功能**: 面試 Agent 啟動，包含：
  - 給面試問題
  - 分析使用者答案並評判
  - 給出標準答案
- **特點**: 除非說退出不然會一直下一題

### 階段 4: 面試總結階段
- **觸發**: 輸入「結束面試」
- **功能**: 統合前面所有面試過程給出建議

## 🚀 使用方法

### 1. 啟動面試
```
點擊「開始面試」按鈕
↓
系統進入自我介紹階段
↓
自我介紹 Agent 啟動
```

### 2. 進行自我介紹
```
直接開始輸入自我介紹內容
↓
系統會記錄所有內容
↓
可以分段輸入，系統會累積收集
```

### 3. 完成自我介紹
```
輸入「完成自我介紹」或「開始面試」
↓
系統分析自我介紹內容
↓
給出評分和改進建議
↓
自動進入面試模式
```

### 4. 面試問答
```
系統自動出第一題
↓
回答問題
↓
系統分析答案並評分
↓
自動準備下一題
↓
重複直到結束
```

### 5. 結束面試
```
輸入「結束面試」
↓
系統生成面試總結
↓
包含整體表現和改進建議
```

## 🎮 快捷操作

### 自我介紹階段按鈕
- **完成自介**: 完成自我介紹並進入分析
- **重新開始**: 重置面試流程

### 面試階段快捷鍵
- **🎯 下一題**: 快速獲取下一題
- **🔄 重新開始**: 重新開始面試
- **🏁 結束面試**: 完成面試並生成總結

## 📊 分析標準

### 自我介紹評分標準
- **優秀 (90-100分)**: 6個標準都完整
- **良好 (80-89分)**: 5個標準完整
- **一般 (60-79分)**: 4個標準完整
- **需要改進 (40-59分)**: 3個標準完整
- **不足 (0-39分)**: 少於3個標準

### 自我介紹評分顯示
當您完成自我介紹後，系統會：

1. **🎯 即時評分**: 顯示 0-100 分的總評分
2. **📊 評級分類**: 優秀/良好/一般/需要改進/不足
3. **📋 完成率**: 顯示 6 個標準的完成狀況
4. **💡 分析摘要**: 詳細分析每個標準的完成情況
5. **🔍 改進建議**: 提供具體的改進方向

**評分顯示特色**:
- 🎨 美觀的漸層背景設計
- 📱 響應式佈局，適合各種設備
- ⏰ 延遲顯示快捷按鈕，讓用戶專注於評分結果
- 🔄 自動進入面試模式

### 面試答案評分
- **評分範圍**: 0-100分
- **相似度**: 與標準答案的匹配程度
- **具體差異**: 指出答案的不足之處
- **改進建議**: 提供具體的改進方向

## 🔧 技術特點

### Agent 管理
- **階段控制**: 嚴格控制 Agent 的啟動順序
- **狀態管理**: 完整的會話狀態追蹤
- **記憶功能**: 支援 Redis 和 PostgreSQL 的資料儲存

### 智能分析
- **關鍵詞檢測**: 基於流程.txt 的 6 個標準
- **內容評估**: 自動檢測內容完整性和質量
- **個性化建議**: 根據分析結果提供具體建議

## 📝 使用建議

### 自我介紹準備
1. **結構化**: 按照 6 個標準準備內容
2. **具體化**: 提供具體的數據和例子
3. **相關性**: 強調與應徵職位的連結
4. **時長控制**: 控制在 1-2 分鐘內完成

### 面試技巧
1. **STAR 方法**: 使用情境-任務-行動-結果的結構
2. **具體回答**: 避免空泛的表述
3. **持續學習**: 根據分析結果改進

   ```bash

   python -m uvicorn fastapi_app:app --host 0.0.0.0 --port 8001 --reload
   ```
