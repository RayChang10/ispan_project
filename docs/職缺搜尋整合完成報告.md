## 🔄 工作流程設計

按照 `withLLM.txt` 的設計，實現了以下完整工作流程：

```
1. LOGIN (登入) 
   ↓
2. RESUME_INPUT (履歷輸入)
   ↓  
3. JOB_SEARCH (職缺搜尋)
   ↓
4. JOB_SELECTION (職缺選擇)
   ↓
5. FIT_ANALYSIS (契合度分析)
   ↓
6. RESUME_HEALTH_CHECK (履歷健檢)
   ↓
7. MOCK_INTERVIEW (模擬面試) - 使用現有系統
   ↓
8. COMPLETION (完成)
```

## 🔌 API 端點清單

### 職缺搜尋 API
- `POST /api/job_search/search` - 一般職缺搜尋
- `POST /api/job_search/search_by_resume` - 根據履歷搜尋
- `POST /api/job_search/analyze_fit` - 契合度分析
- `POST /api/job_search/resume_health_check` - 履歷健檢
- `GET /api/job_search/status` - 服務狀態檢查

### 工作流程管理 API
- `POST /api/workflow/set_resume` - 設定履歷
- `POST /api/workflow/search_jobs` - 職缺搜尋
- `POST /api/workflow/select_job` - 選擇職缺
- `POST /api/workflow/analyze_fit` - 分析契合度
- `POST /api/workflow/resume_health_check` - 履歷健檢
- `POST /api/workflow/start_mock_interview` - 開始模擬面試
- `GET /api/workflow/status` - 獲取工作流程狀態
- `POST /api/workflow/reset` - 重置工作流程

## 🛠️ 技術架構

```
用戶介面 (Frontend)
```

## 🚀 部署指南

### 1. 環境設定
```bash
# 設定環境變數
export OPENAI_API_KEY="your_openai_api_key"
export MILVUS_HOST="localhost"
export MILVUS_PORT="19530"

# 安裝依賴
pip install -r requirements.txt
```

### 2. 啟動 Milvus 服務
```bash
cd commitLLM
docker-compose up -d
```

### 3. 設定職缺資料庫
```bash
python scripts/setup_job_search_data.py
```

### 4. 測試整合功能
```bash
python scripts/test_job_search_integration.py
```

### 5. 啟動後端服務
```bash
python -m uvicorn backend.fastapi_app:app --host 0.0.0.0 --port 8001 --reload
```

### 6. 示範工作流程
```bash
python scripts/demo_job_search_workflow.py
```

## 📝 使用範例

### 基本職缺搜尋
```python
from backend.fast_agent_bridge import call_fast_agent_function

result = call_fast_agent_function(
    "search_jobs",
    user_query="Python 開發工程師",
    top_k=10
)
```

### 完整工作流程
```python
from backend.unified_workflow import process_workflow_request

# 設定履歷
result = process_workflow_request("set_resume", resume_data=resume_data)

# 搜尋職缺
result = process_workflow_request("search_jobs", query="Python")

# 選擇職缺
result = process_workflow_request("select_job", job_index=0)

# 分析契合度
result = process_workflow_request("analyze_fit")
```
